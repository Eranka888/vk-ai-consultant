# ИИ-консультант для сообщества ВКонтакте

ИИ-бот для автоматизации первого общения с подписчиками сообщества ВКонтакте.

Проект создан для ситуации, когда владельцу сообщества приходится многократно отвечать на одинаковые вопросы, вручную выдавать материалы и переводить человека к следующему шагу.

---

## 🎯 Задача проекта

Создать помощника, который сможет взять на себя часть первого общения с подписчиками и работать на основе информации конкретного сообщества.

Бот должен:

- отвечать на типовые вопросы;
- использовать собственную базу знаний;
- выдавать пользователю нужные материалы;
- поддерживать естественный диалог;
- помогать перейти к следующему этапу взаимодействия;
- сокращать количество повторяющихся ручных действий владельца сообщества.

---

## ⚙️ Как работает

1. Пользователь пишет сообщение сообществу ВКонтакте.
2. Бот получает сообщение через VK API.
3. Запрос обрабатывается с учетом системных инструкций и базы знаний.
4. GigaChat формирует ответ.
5. Бот отправляет его пользователю во ВКонтакте.
6. В зависимости от запроса пользователь получает ответ, материал или предложение следующего действия.

---

## 🧩 Что реализовано

- подключение бота к сообщениям сообщества ВКонтакте;
- интеграция с GigaChat API;
- отдельная база знаний;
- системные инструкции для поведения ИИ-консультанта;
- работа с контекстом диалога;
- обработка пользовательских сообщений;
- безопасное хранение ключей через переменные окружения.
